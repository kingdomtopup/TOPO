UP AND RUNNING

Start small.
Ship confidently.

Install the package, then create a client on your server. Your Bakong API token should be kept private and supplied through a secure environment variable.

Read the full documentation ↗
quick_start.pyPYTHON
import os
from khqr_payment import KHQRClient

client = KHQRClient(os.environ["BAKONG_API_TOKEN"])

qr = client.create_qr_string(
    merchant="yourname@bank",
    merchant_name="Sunday Coffee",
    merchant_city="Phnom Penh",
    amount=12.50,
    currency="USD",
)

print(qr.string)
print(qr.md5)  # use to check status
